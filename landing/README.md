# لاندينغ الاستشارة حسب الهدف / المرض

صفحة واحدة (`index.html`) بدون أي مكتبات. أول خطوة يختار الزائر هدفه، ولكل هدف أسئلة خاصة فيه.

## الأهداف ورابط كل واحد (للإعلانات)

| الهدف | الرابط |
|---|---|
| رشاقة | `?goal=rashaqa` |
| كرش | `?goal=karsh` |
| سكري | `?goal=sukari` |
| ضغط | `?goal=dhaght` |
| قولون | `?goal=qolon` |
| خمول | `?goal=khumool` |
| آلام المفاصل | `?goal=mafasel` |
| امساك | `?goal=imsak` |
| تكيس | `?goal=takayos` |
| حمل و رضاعة | `?goal=haml` |

بدون `goal` تظهر قائمة الأهداف. أي `utm_*` في الرابط يُحفظ مع سجل الزيارة.

## ترتيب الأسئلة

1. الهدف
2. سؤال أو سؤالين خاصة بالهدف
3. الجنس (لا يُسأل في تكيس وحمل و رضاعة)
4. الطول والوزن
5. **رقم الواتساب** ← يُنشأ العميل فوراً في `POST /api/diet-leads`
6. العمر + باقي أسئلة الهدف + ملاحظات ← كل إجابة تُحدّث العميل في `PUT /api/diet-leads-edit`
7. صفحة النتيجة وزر واتساب برسالة فيها كل البيانات

الرقم يُطلب قبل الأسئلة التفصيلية، فحتى لو خرج الزائر بعده يبقى العميل مسجلاً مع هدفه.

## الإعدادات

في أول السكربت داخل `CONFIG`: رابط الـ API، قيمة `source`، رقم واتساب احتياطي، الشعار، ومجلد صور آراء العملاء
(`/images/feedback/<اسم المجلد>/01..07.webp` — الصور غير الموجودة تختفي تلقائياً).
